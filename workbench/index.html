[login_status]
Login Status
Compact inline status bar. Shows the current player handle when logged in, or a login link when anonymous. Fires element_games_reload_all on logout to refresh all widgets on the page.

[element_games]
Games Catalog
Responsive game card grid. Fetches from GET /api/games server-side and pre-renders. After load, elementGamesHydrate() fills per-user completion context in one batch call. Supports vertical + horizontal layouts, paged and view-more modes.
layout: vertical / horizontal columns 1–4 display mode show_points show_difficulty show_categories

[element_theme_details]
Theme Details (Static)
Hardcoded monthly curator block. Content is authored directly in the shortcode attributes or WP page editor — no API call. Includes curator headshot, game roster with difficulty + availability, and the dvmIQ challenge callout.
static content curator headshot game roster dvmIQ block completion rings

[element_themes]
Theme Details (Dynamic)
Data-driven version of the theme block. Fetches from GET /api/games/themes server-side, renders one block per theme returned. Completion rings are hydrated client-side by the shared elementGamesHydrate() function alongside game cards.
show_curator toggle show_dvmiq toggle completion rings multi-theme API-driven
